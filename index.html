11 Semantic Tags

1. Header

A header is a text that you can select and change something about it. you can put headers at the top of the entire page or at the start of any independent content sections

2. Nav

Example Link

The nav tag does do anything on its own, but with a anchor tag it creates a clickable link with blue text as shown. This is just a example so the link wont do anything when you click on it.Although this tag doesnt make that much of a difference to us, its very significant for the computer. It helps by showing the computer which links are the most important pages on your website.

3. Main

The main tag also isnt a visual form of code. The main tags tells the browser that this is the most important text in the website so it prioritizes the text in the main over any other text, such as headers and footers. It is also very similar to the header tag.

4. Section

the section tag is primarily used to group together related content to that its all together and not all over the place. This is also similar to main and header.

5. Article

The article tag is used to wrap individual information. The opposite of the section tag.

6. Aside

The aside tag is text that is indirectly related to the main content around it such as sidebars, quotes, or definitons.

7. Figure

The figure tag is used to wrap an independent images, diagrams, charts, or code snippets usually including a caption.

8. Fig caption

A figcaption tag is used to put a caption on a image, diagram, chart, or code snippet with a figure tag wrapped around the img.

9. Details

Definiton of details tag. (click the arrow)

This is a arrow you can click to show more information.

10. Summary

The summary tag is the text in the details section "Definiton of details tag. (click the arrow)".

11. Footer

The same as header, but at the bottom of the page instead of the top.
